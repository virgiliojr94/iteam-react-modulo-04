# Aula 01 — Primeiro app React

## Delta do dia

Hoje você vai criar a primeira versão do projeto **My Daily Habits**.

Ao final da atividade, o projeto deve:

- ter sido criado com **React + Vite**;
- executar localmente sem erro;
- exibir uma alteração feita por você na tela;
- estar salvo em `alunos/seu-nome-completo/my-daily-habits/`;
- ter a evidência da aula registrada em Markdown;
- estar versionado no GitHub.

## Faça

1. Dentro da sua pasta em `alunos/seu-nome-completo/`, crie o projeto `my-daily-habits` com Vite e React.
2. Instale as dependências.
3. Execute o projeto localmente.
4. Altere o conteúdo inicial exibido na página para algo relacionado ao **My Daily Habits**.
5. Confirme no navegador que sua alteração apareceu.
6. Copie `templates/EVIDENCIA.md` para `alunos/seu-nome-completo/evidencias/aula-01.md` e preencha somente o necessário.
7. Faça o commit da atividade e envie para o seu fork.

## Pronto quando

- o app abre no navegador;
- sua alteração aparece na tela;
- o projeto continua funcionando após a alteração;
- `evidencias/aula-01.md` mostra o resultado;
- o commit da Aula 01 está visível no GitHub.

## Fora do escopo hoje

Não avance para Hooks, props, estado ou outras funcionalidades do React. O foco desta aula é somente **ambiente, primeiro componente e ciclo editar → visualizar → versionar**.

> Se precisar rever o fluxo de fork, clone, upstream, commit, push ou Pull Request, consulte `GUIA-GITHUB.md` e `COMO-ENTREGAR.md`.
