# Atividades

As atividades são liberadas **uma por dia**.

Apenas as aulas já liberadas estarão disponíveis neste diretório.

Exemplo:

```text
atividades/
├── aula-01/
│   └── README.md
├── aula-02/
│   └── README.md
└── ...
```

Se a próxima atividade ainda não aparece:

1. confirme que o professor já a liberou;
2. execute:

```bash
git pull --no-rebase upstream main
git push origin main
```

Não procure atividades futuras em branches, tags ou arquivos ocultos: elas ainda não foram publicadas.
